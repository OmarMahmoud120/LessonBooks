---
name: release-checklist
description: "Prepare an explicitly requested LessonBooks release for review before deployment."
---

Read doc/milestones.md and doc/privacy-compliance.md. Run npm run check; build backend, site and mobile player artifact. Run schema, privacy, security, accessibility/RTL and pedagogy reviewers. Confirm rollback, secrets injection, provider allowlist, budget, consent, deletion, retention and monitoring are configured. Record evidence and unresolved blockers. Deployment, push, paid calls and app-store submission require explicit authorization; this skill does not grant it.
