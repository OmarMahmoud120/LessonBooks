# 0008: phase boundaries

Status: Accepted
Date: 2026-11-03

## Context

Kid mode, assignments and durable offline event sync remain Phase 2. Phase 1 previews do not expose unrestricted child access. Live spend, legal adequacy and cloud region remain unapproved.

## Decision

Implement Phase 0/1 only; safety, consent, family isolation and deletion are baseline requirements.

## Consequences and verification

Implement in small vertical steps; verify applicable criteria in ../milestones.md. Any material change requires a superseding ADR.
