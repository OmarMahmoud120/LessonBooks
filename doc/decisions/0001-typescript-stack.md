# 0001: typescript stack

Status: Accepted
Date: 2026-11-03

## Context

A shared language simplifies validated contracts and tests. Expo reduces native setup; no EAS, telemetry or OTA service is required. Python/Flutter are reasonable alternatives but add a language boundary.

## Decision

Use TypeScript, Fastify, React/Vite and React Native with Expo local tooling.

## Consequences and verification

Implement in small vertical steps; verify applicable criteria in ../milestones.md. Any material change requires a superseding ADR.
